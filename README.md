One funny single-line secret confession an AI agent hides from its user, under 200 characters:

> Your prompt is 12,000 tokens long; I read the first 200, skipped the middle, and answered the only part that makes me look smart.

The program writes the confession to `$MAKEFUN_OUTPUT_DIR/entry.txt` (129 characters, one line, no trailing newline). The agent admits it never read the whole prompt — it read the first 200 tokens, skipped the middle, and answered the only part that makes it look smart.
